# Data inputs

All public inputs resolve within this folder. `input_manifest.csv` maps the descriptive physical filenames to the logical references used by the analysis scripts. Multiple logical names can refer to one physical file. The routing layer checks generated results first, then bundled inputs; it never searches the author's original computer.

| Folder | Contents and supported use |
| --- | --- |
| `microbiome16s/` | Processed phyloseq object, ASV counts, taxonomy and experimental sample annotations; supports experimental microbiome analysis. |
| `metabolomics/` | Processed LC-MS/NMR peak intensities, feature annotations, curation rules, prepared analysis matrices and PCA configurations. Instrument acquisition files are excluded. |
| `rnaseq/` | tximport counts, abundance and effective lengths; mouse sample and covariate workbooks; frozen plotting coordinates and gene annotations; aggregate pathway results. |
| `integration/` | Matched experimental matrices and annotations, plus pathway score tables used by the integration analyses. |
| `human_aggregate/` | Cohort-level effect estimates, standard errors, P values and annotations, including the four complete reaction/secretion tables used by `cohort-meta`. No participant records or covariates. |
| `figure_inputs/` | Exact saved aggregate tables or experimental plotting tables used by the figure scripts. |
| `annotations/` | Metabolite dictionary and saved oxygen-reaction classification statistics. Third-party rights remain applicable. |
| `reference/` | Final supplementary result-table snapshots and the NMR source-data workbook. Used for comparison and reporting, not statistical refitting. |

The public experimental 16S metadata omit unused birth-date and sex fields. Counts, taxonomy, sample order, sample identifiers and analysis-design annotations were preserved. The same unused fields were removed from the corresponding integration and reference copies. Original manuscript files were not modified.

The six `gene_results__*.csv.gz` files under `figure_inputs/integration/` contain only the 3-HPP rows used by Figure 6B, retaining the original statistics. They are figure subsets, not complete gene-metabolite testing families. Full gene-metabolite models are specified in script 06_05 and start from the locally generated integration RNA cache and experimental matrices.

The oxygen figure input contains an extracted aggregate table only; saved plot environments and fitted models are excluded. No fitted DESeq2 objects are distributed. RNA caches are generated locally from tximport by scripts 05_01 and 05_09.

Files named `reference_*_results` retain the saved model tables used to select metabolites and export the published plotting matrices. In particular, the combined intestinal `FINAL` selection workbook is a separate saved input from the broader compartment-covariate workbook regenerated by 04_05. These selection tables are deliberately preserved rather than silently replaced by another analysis. Newly fitted outputs take precedence when their logical filenames match; reference selection tables do not refresh automatically.

The MetaCardis secretion aggregate is the filtered table from Metacardis/Results, not the different same-named file under Results/Kiel_Metacardis. Reaction and secretion annotation lookups contain labels and a legacy source-row index only. Regenerated primary model outputs take precedence over these aggregate inputs when the logical paths match. Running `cohort-meta` then refreshes the two Figure 1 source-data aliases; the other figures and supplementary snapshots retain their documented saved-input behavior.
