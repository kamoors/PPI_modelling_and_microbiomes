# Input data

| Folder | Contents |
| --- | --- |
| `microbiome16s/` | Processed experimental phyloseq object, ASV counts, taxonomy and sample annotations |
| `metabolomics/` | Processed LC-MS/HILIC and NMR intensities, feature annotations, curation rules and prepared model inputs |
| `rnaseq/` | Gene-level tximport matrices, mouse sample metadata and covariates, saved plotting coordinates, gene annotations and aggregate pathway results |
| `integration/` | Matched experimental matrices and pathway score tables |
| `human_aggregate/` | Cohort-level effects, standard errors, P values and annotations; no participant records or clinical covariates |
| `figure_inputs/` | Saved aggregate or experimental plotting tables used by the figures |
| `annotations/` | Metabolite dictionary and saved oxygen-reaction statistics |
| `reference/` | Final supplementary result snapshots and NMR source-data workbook |

`files.csv` maps the input references in the scripts to files in this folder. Several references can point to the same file. The shared setup checks for matching newly generated results before reading a supplied input. It does not search the author's computer.

The experimental data allow refitting from processed measurements. Raw reads, instrument acquisition files, metabolic models, fitted DESeq2 objects and participant-level human cohort data are not included. RNA caches are built locally from tximport by 05_01 or 05_09. Unused experimental birth-date and sex fields have been omitted from the 16S and corresponding integration metadata.

Saved inputs serve the following specific purposes:

- `reference/` supplies the supplementary workbook builder. Running the builder assembles the saved results rather than refitting them.
- Metabolomics files named `reference_*_results` supply the published feature selections. In particular, the combined intestinal selection workbook differs from the broader compartment-covariate workbook generated by 04_05; the selection does not update automatically after refitting.
- Figure 5 uses saved PCA coordinates and gene annotations. Integration input preparation also uses saved pathway/GSEA results.
- The six `gene_results__*.csv.gz` files in `figure_inputs/integration/` contain the 3-HPP rows plotted in Figure 6B. They retain their original statistics but are not complete gene-metabolite testing families. Script 06_05 fits the full models.
- Human aggregate tables support reaction-abundance, secretion and blood-flux meta-analyses. Scripts 01_11 and 01_12 also update the matching Figure 1 source tables. The MetaCardis secretion input is the table used for the downstream manuscript results.
- The oxygen figure input contains aggregate reaction statistics, without fitted models or saved plot environments.
