# Run order

Run scripts using `run.R`; they rely on the runner's input/output routing. Numbering follows the manuscript, with 00 reserved for helpers. Script 01_05 contains the validated reconstruction of the primary MetaCardis reaction model. New scripts are appended within their manuscript section to preserve existing script names.

| Command or scripts | Starting point | Output |
| --- | --- | --- |
| `--workflow cohort-meta` | Bundled aggregate Kiel and MetaCardis HC3 tables | Current reaction and secretion fixed-effect meta-analyses; refreshed Figure 1 source-data aliases |
| `--workflow metacardis-primary` | Separately authorised participant metadata, reaction abundance and secretion matrices | Reconstructed manuscript-matching MetaCardis primary models; unavailable publicly |
| `--script 02_06_kiel_blood_flux_associations.R` | Separately authorised Kiel metadata and original blood-flux MAT files | Validated primary Kiel blood HC3 model and PCA diagnostics |
| `--workflow rna-limma` | Original/all-sample cache generated by 05_01 | Recovered primary donor-blocked limma-voom branch, excluding C02/G04; enrichment is not run |
| `--workflow metabolomics-refit` | Bundled prepared experimental matrices and NMR intensity tables | Serum, intestinal, caecum NMR, ex vivo NMR and HILIC model tables |
| `--workflow serum` | LC-MS feature workbooks and curation rules | Recreates serum inputs then fits limma; additional historical mixed models require lmerTest |
| `--workflow intestinal` | LC-MS feature workbooks and curation rules | Recreates intestinal inputs and models |
| `--workflow hilic` | HILIC feature workbooks | Recreates ex vivo inputs and primary combined-mode analysis, with mode-separated sensitivity |
| `--workflow ordination` | Processed metabolomics inputs | PCA configurations and donor-restricted Procrustes test |
| `--script 04_11_test_metabolomics_ordination.R` | Bundled saved PCA score configurations | Procrustes statistics and coordinates |
| `--workflow rna-primary` | tximport and mouse metadata | Initial all-sample cache, then primary contrasts after C02/G04 exclusion and refiltering |
| `--workflow rna-enrichment` | Previously generated primary cache | Preserved additional RNA reporting, GO and GSEA; requires annotation packages and MSigDB access |
| `--script 05_05_rna_covariate_sensitivity.R` | Primary cache and mouse covariates | Covariate sensitivity fits |
| `--script 05_06_liver_go_enrichment.R` | Published DESeq2/limma result tables in reference snapshot | Directional GO comparison; requires org.Mm.eg.db and clusterProfiler |
| `--workflow rna-integration-cache` | tximport and mouse metadata | Independent cache excluding C02/G04 before filtering; needed by 06_05 |
| `--script 05_11_pathway_metabolite_associations.R` | Integration cache and GSEA outputs | ssGSEA/pathway-metabolite analysis; requires GSVA and annotation/database dependencies |
| `--workflow integration` | Experimental matrices, matched RNA metadata and saved pathway/GSEA tables | Input preparation, genus-metabolite fits and summaries |
| `--workflow integration-from-prepared` | Bundled matched-input object | Genus-metabolite fits and summaries without repeating input preparation |
| `--script 06_05_gene_metabolite_associations.R` | Integration cache, prepared matrices, annotation packages and gene sets | Full gene-metabolite DESeq2/enrichment analyses; potentially lengthy |
| `--script 06_06_export_integration_figure_tables.R` | Full local integration results, including 06_05 | Focused figure-table exports |
| `--workflow figures` | Saved figure inputs bundled here | Main Figures 1–6; some scripts also compute plotting statistics |
| `--script 05_08_plot_supplementary_transcriptomics.R` | Saved GO and normalized expression plotting tables | Supplementary transcriptomics figure |
| `--workflow supplementary` | Published reference table snapshots | Five Supplementary Data workbooks; reporting only |

03_02 runs the processed experimental 16S ordination and Bray–Curtis analysis. Use `--script 03_03_export_bray_curtis_data.R` to export the same Bray–Curtis table without graphics dependencies. Raw DADA2 processing (03_01) requires separately supplied reads and reference resources. Oxygen model extraction (01_07) requires separately supplied models via `config/local.R`; saved reaction statistics support 01_08 without models.

Scripts marked `restricted_human` require unavailable participant-level data and are excluded from public workflows. 02_02 performs blood-flux meta-analysis from bundled cohort-level statistics. 02_04 combines saved aggregate blood-flux and serum results. The wider historical PCA statistics are retained under `scripts/optional/`; they include exploratory tests removed from the manuscript and are not run by the primary ordination workflow.

Enrichment results can depend on database and package versions, and stochastic analyses depend on their recorded seeds and permutation settings. Recovered expressions are retained where available; the validated MetaCardis and fixed-effect meta-analysis reconstructions are explicitly identified in SOURCE_UPDATES_20261113.md. Run in a clean R session, as the runner does, and inspect the environment and output manifests.
