# Source recovery and validation update 13 November 2026

Version 0.5.0 adds the recovered primary Kiel blood and RNA limma scripts and validated reconstructions of the MetaCardis reaction/secretion models and their meta-analyses. Participant-level cohort data and covariates remain excluded.

## MetaCardis models and aggregate inputs

- `01_05_metacardis_reaction_abundance.R` reconstructs the primary reaction model from `Metacardis_react_ab_HC3_boot_noPPIExclusion_analysis.R`. It retains the natural-log transformation, 1e-6 pseudocount, total reaction-abundance adjustment and metabolomics exclusion. Systolic blood pressure is omitted to reproduce the final results. All 7,713 reactions match across the eight numerical primary result columns, including FDR and confidence intervals.
- `01_10_metacardis_metabolite_secretion.R` reconstructs the full secretion model from `Metacardis_mg_sec_HC3_boot.R`, restoring the same participant exclusion and retaining systolic blood pressure and log1p response. All 269 metabolites match across the eight numerical primary result columns. Metabolite annotations and the legacy source-row index are retained separately from the model fits.
- Both scripts remove participants recorded as non-users when metabolomics detects PPI. The retained metadata ID set contains 997 participants; the final model complete-case counts differ by analysis. Reported users with undetected PPI are retained.
- The existing `02_03_metacardis_serum_associations.R` is the matching serum version; it retains the exclusion and omits systolic blood pressure and antihypertensive-drug terms from the full formula. All 1,513 source results previously matched the downstream table.

The primary reaction and secretion scripts were executed through the public package runner using the separately authorised local cohort inputs. Their outputs matched the reference tables. The final secretion export additionally restores the source-row and column ordering; statistical values are unchanged. These are explicitly identified reconstructions, not claims that the unchanged historical files were the final generators. Bootstrap and historical BASE branches are not run by these primary scripts.

## Meta-analysis and Figure 1 connections

The four full cohort aggregate-statistics inputs are now bundled under `data/human_aggregate/`, with reaction and metabolite annotation lookups under `data/annotations/`. No participant rows or adjustment covariates were added.

`cohort-meta` runs `01_11_meta_analyse_reaction_abundance.R` and `01_12_meta_analyse_predicted_secretion.R`. They use the actual HC3 standard errors from both cohorts for inverse-variance fixed-effect meta-analysis and apply BH correction over shared features. The correct secretion input is the filtered MetaCardis/Results table, rather than the different same-named Results/Kiel_Metacardis table. The current Kiel secretion table replaces the older or missing paths in the historical comparison scripts.

All 7,493 shared reaction rows and 253 shared secretion rows matched the final meta-analysis and Figure 1 source tables. Checks passed both from bundled aggregate statistics and after the newly packaged private-data primary fits. The workflows register updated logical Figure 1 source-data aliases, so a subsequent Figure 1 run in the same results directory reads the new meta-analysis exports. Other figure inputs and supplementary workbook assembly retain their documented frozen-table behavior.

The public `cohort-meta` workflow also ran successfully after moving the complete package to a directory containing spaces. Input checks passed for all 119 logical aliases and 107 distinct inputs; all 67 R scripts parsed. The MATLAB assembly wrapper is a separate manual entry point.

## Recovered Kiel blood and RNA code

`02_06_kiel_blood_flux_associations.R` makes the metadata prerequisites and current MAT input path explicit. The recovered primary model was previously refitted from all 1,280 original MAT files: all 317 reaction results matched the saved CSV, the workflow RDS read by meta-analysis and the public aggregate input. All 299 Kiel rows in the packaged blood meta-analysis and Supplementary Data 1 also matched. Its original fitting and extraction helper bodies were verified unchanged apart from filesystem routing. PCA showed only small unseeded numerical variation; one glucose field outside the model differed in metadata comparison. This script's later integration into the runner was checked structurally; a second full raw-MAT run was not repeated for packaging.

`05_12_primary_limma_donor_blocked.R` preserves the recovered primary limma-voom/duplicateCorrelation function and the C02/G04-excluded invocation. Its original saved output matches all 38,694 gene–organ records in the primary Supplementary Data 3 table across six numerical columns. It requires the original/all-sample cache generated by 05_01, rather than the independently filtered integration cache. Four helper bodies were verified unchanged apart from filesystem routing. No new limma fitting or enrichment run is claimed in this package update.

## Agreed validation scope

The current manuscript and all five final supplementary workbooks were checked. They contain cohort sex descriptions, donor matching, sex-adjusted analyses and sex-specific host-model selection, but no sex-stratified association tables or PPI-by-sex interaction results. Those exploratory branches and their exports were removed from the packaged MetaCardis blood script; all other retained expressions were verified identical. Original project scripts and result files were left intact.

The full enrichment and integration pipelines were retained and were not rerun in this update, as requested. Existing validation records remain available; saved results are not described as fresh independent recomputations. No additional rerun of unreported sex-stratified analyses is required for this release. Persephone is documented as external software, with only the project-specific assembly wrapper included; no complete upstream model-construction validation is claimed.

The noncommercial licence and restricted-data notices are unchanged. Detailed public-safe comparisons and source hashes are recorded in `provenance/validation_cohort_meta_20261113.csv`, `provenance/validation_primary_and_meta_20261113.csv`, `provenance/recovered_helper_checks_20261113.csv`, `provenance/validation_scope_20261113.json` and `provenance/source_updates_20261113.json`.
