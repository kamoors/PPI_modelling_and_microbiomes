# PPI modelling and microbiomes

Repository accompanying the study:

**Proton pump inhibitor-associated microbiomes shape systemic host responses**

Karlis A. Moors and colleagues.

This study investigates the metabolic and host transcriptional effects of microbiomes associated with proton pump inhibitor (PPI) use. It combines human cohort analyses, microbial community and whole-body metabolic modelling, ex vivo faecal cultivation, and microbiota transfer into germ-free mice, together with metabolomics and RNA sequencing.

## Code availability

The analysis code and instructions for running it will be publicly released in this repository upon publication of the peer-reviewed article. This repository currently contains study information and the code release plan.

Code will be shared confidentially with editors and reviewers during peer review.

## Planned analyses

- Human cohort microbiome and metabolomics associations, including cross-cohort meta-analysis.
- Microbial reaction abundance, predicted metabolite secretion, oxygen-tolerance classification and whole-body metabolic modelling analyses.
- Experimental 16S rRNA gene sequencing analyses.
- LC-MS and NMR metabolomics analyses.
- Mouse tissue RNA-seq differential expression and pathway enrichment.
- Cross-layer associations between microbial genera, metabolites and host gene expression.
- Figure generation and supplementary data assembly.

The code release will include software dependencies, input requirements, run instructions and documented limitations.

## Data availability

Study data are distributed separately from the code. Dataset accessions, supplementary data and conditions for accessing human cohort data are described in the manuscript's Data availability section.
